# Журнал выдачи оборудования (Windows Forms)

Контрольная работа по дисциплине «Windows Forms & WPF».

## Вариант

| Параметр | Значение |
|---|---|
| Формат инвентарного номера | `LAB-123` (префикс + 3 цифры) |
| Максимальный срок выдачи | 7 календарных дней |
| День выдачи | нулевой |
| Просрочка начинается | на следующий день после срока возврата |

Параметры варианта задаются в одном месте — файл `Variant.cs`:

```csharp
public const string Prefix = "LAB"; // префикс номера
public const int MaxDays = 7;       // максимальный срок выдачи
```

## Требования

- Windows 10/11
- .NET SDK 8.0 (или Visual Studio 2022 с рабочей нагрузкой «Разработка классических приложений .NET»)

> Windows Forms запускается только на Windows.

## Запуск

```bash
dotnet run
```

или открыть `InventoryApp.sln` в Visual Studio и нажать F5.

## Как пользоваться

- **Добавить** — открывает диалог новой выдачи. Номер проверяется по формату варианта,
  повторная открытая выдача на тот же номер запрещена.
- **Изменить** — открывает выбранную запись (или двойной клик по строке).
  «Отмена» не меняет данные.
- **Вернуть** — фиксирует возврат выбранного предмета (дата возврата = сегодня).
- **Поиск** — по получателю или инвентарному номеру, работает вместе с фильтром по статусу.
- Просроченные строки подсвечиваются розовым.

Статус не хранится в файле, а вычисляется:

- есть дата возврата → «Возвращено»;
- иначе `сегодня > срок возврата` → «Просрочено»;
- иначе → «Выдано».

## Сохранение данных

Записи хранятся в JSON-файле `issues.json` рядом с исполняемым файлом
(`bin/Debug/net8.0-windows/issues.json`). Файл создаётся автоматически при первом
сохранении и читается при запуске приложения.

## Структура проекта

| Файл | Назначение |
|---|---|
| `Program.cs` | точка входа, запуск главной формы |
| `Variant.cs` | параметры варианта и проверка номера |
| `Issue.cs` | модель записи и вычисляемый статус |
| `IssueStorage.cs` | сохранение/загрузка JSON |
| `MainForm.cs` | таблица, поиск, фильтр, кнопки |
| `IssueForm.cs` | диалог добавления/редактирования и проверка данных |
